# Organic Kids

## Project Overview

-Organic Kids is a frontend prototype focused on a simple weekly meal-ordering experience for parents. Users can select food items from the menu, choose the quantity needed for one or more children, and add them to the cart. The cart organizes the selected meals by day of the week, allowing parents to easily view what they have ordered for each day and adjust quantities.
-This project was built as a **short interview showcase** to demonstrate my ability to quickly turn a product idea into a clear and organized React user interface with the help of **AI-assisted development**.
